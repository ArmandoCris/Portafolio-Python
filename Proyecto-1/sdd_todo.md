Rol: Eres un desarrollador experto en Python y CustomTkinter.
Tarea: Crear la interfaz gráfica base para una aplicación de tareas (To-Do App).
Requerimientos de UI:

Una ventana principal de 500x600 píxeles.

Tema oscuro por defecto.

Un campo de entrada de texto (CTkEntry) en la parte superior para escribir una nueva tarea.

Un botón (CTkButton) al lado del campo de texto con el texto "Agregar Tarea".

Un marco desplazable (CTkScrollableFrame) debajo, que ocupará el resto de la ventana. Aquí se listarán las tareas más adelante.
Estructura del código: Utilizar Programación Orientada a Objetos (POO). Crea una clase ToDoApp que herede de customtkinter.CTk.
